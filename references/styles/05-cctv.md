# 05 賽博監控（CCTV）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：相機類
- **適合用途**：資安／AI 視覺品牌、懸疑或科幻活動頁、作品集「被觀察中」主題、互動裝置展

## 視覺特徵清單
- 四角 L 形取景框
- 左上閃爍紅點 REC＋攝影機編號（如 CAM-03）
- 右上逐秒跳動的時間戳（等寬字）
- 螢光綠 1px 追蹤框，四角加粗，旁邊標籤「TARGET 0.97」
- 全畫面掃描線與顆粒層（`pointer-events: none`）
- 鎖定時框轉紅、出現「LOCKED」與放大特寫小窗

## 一句話流程
進場是一段模擬監控畫面 → 追蹤框延遲跟隨游標 → 點擊鎖定（轉紅、LOCKED、特寫小窗放大）→ 切到 Live 模式用自己的鏡頭 → 框自動追著畫面中的移動區

## 迭代順序
1. HUD 骨架：取景框、REC、編號、時間戳
2. 追蹤框外觀與延遲跟隨的手感（lerp 係數）
3. 點擊鎖定與特寫小窗
4. 掃描線、顆粒、輕微暗角
5. Live 模式：鏡頭＋格差分偵測
6. 手機、權限被拒、減少動態

## 技術棧
- 示範畫面：canvas 畫的簡單場景或內嵌短 loop（標示 DEMO）
- 追蹤框：DOM 元素，每幀 `pos += (target - pos) * 0.12`
- 特寫小窗：第二個 canvas，從主畫面 `drawImage` 擷取鎖定區域放大
- Live：`getUserMedia` → 低解析 canvas（如 64×48）→ 前後兩格灰階相減 → 超過閾值的像素算重心與外框 → 對映回全畫面
- 掃描線：重複線性漸層；顆粒：小雜訊圖平鋪＋微位移動畫

## 專屬陷阱
- 格差分在全解析度做會很慢：縮到 64×48 左右再算
- 雜訊會讓框亂跳：閾值＋最少像素數＋位置平滑三道過濾
- 疊層若沒設 `pointer-events: none`，點擊會被掃描線吃掉
- 「TARGET 0.97」這類信心值是裝飾，不要假裝真的在做辨識；Live 模式標示「動態偵測」而非「人臉辨識」
- 時間戳用本機時間即可，但要固定寬度字，否則數字跳動會抖

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「賽博監控 CCTV」首頁，品牌名 {品牌名}，主標 {主標}。

視覺：
- 四角 L 形取景框；左上閃爍紅點 REC 與 CAM-{編號}；右上逐秒跳動的時間戳（等寬字）
- 螢光綠 1px 追蹤框，四角加粗，旁邊小標籤「TARGET 0.97」
- 全畫面掃描線＋顆粒疊層（pointer-events: none），輕微暗角

模式：
- 示範模式（預設）：canvas 畫的模擬監控場景，角落標「DEMO FEED」
- Live 模式（按鈕切換）：開鏡頭，把畫面縮到約 64×48 做前後格差分，框住移動區重心；加閾值與平滑

互動：
- 追蹤框以延遲（lerp）跟隨游標／手指
- 點擊鎖定：框轉紅、標籤變「LOCKED」，角落出現放大特寫小窗；再點一次解除

技術約束：
- 鏡頭需 localhost 或 HTTPS；權限被拒或無鏡頭時頁內說明並留在示範模式
- 手機：Pointer Events，觸控位置即目標；顆粒層降低強度；100dvh
- prefers-reduced-motion：取消顆粒動畫與 REC 閃爍，追蹤框直接跳到目標
- 不宣稱人臉辨識；Live 標示「動態偵測」

不可做：不要做成駭客終端機綠字瀑布；不要讓疊層擋住點擊；不要整片綠色濾鏡。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：賽博監控畫面（CCTV 取景 HUD＋追蹤框）
- **情緒關鍵字**：被注視、冷峻、懸疑、精準
- **配色**：畫面偏冷灰藍；HUD 白；追蹤框螢光綠 #39FF88；鎖定紅 #FF3B3B；REC 紅點
- **材質**：掃描線、顆粒、暗角、低畫質監控感
- **版面**：單屏全幅畫面；HUD 貼四角；主標低調壓在下方；手機同構
- **核心互動**：追蹤框延遲跟隨；點擊鎖定轉紅並跳出特寫小窗
- **一句話流程**：進場看監控畫面 → 框跟著游標 → 點擊鎖定 → 切 Live 用自己的鏡頭
- **不可做**：駭客綠字瀑布、整片綠濾鏡、HUD 擋主標
- **要交付的畫面**：首屏示範畫面、追蹤中、LOCKED＋特寫小窗、手機首屏
```
