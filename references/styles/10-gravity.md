# 10 重力感應（Gravity）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：Canvas 動態場
- **適合用途**：實驗室／新創產品首頁、數據或科學主題品牌、互動作品集、活動倒數頁

## 視覺特徵清單
- 米白底、黑色物件、螢光綠點綴
- 游標是一個引力源（可見的小圓與引力範圍淡圈）
- 物件分輕、中、重：輕的漂浮、中的被吸、重的墜落後碰撞回彈
- 數字粒子組成的球體（例如年份或關鍵數字）
- 可拖曳的大字、可丟擲的「實驗卡片」

## 一句話流程
進場物件靜靜落在地面 → 游標靠近把輕物件吸起 → 拖曳大字丟出去撞散數字球 → 手機傾斜讓所有東西滑向一側 → 點「重置」歸位

## 迭代順序
1. 物件分級：輕／中／重的質量、摩擦、彈性先調對
2. 游標引力的範圍與強度
3. 拖曳與丟擲手感
4. 數字粒子球
5. 手機傾斜（含 iOS 權限）
6. 一般觸控模式、低動態模式

## 技術棧
- Matter.js（cdnjs 固定版本）做剛體：牆、地板、文字與卡片的矩形 body
- DOM 物件跟隨 body 的位置與角度（文字可被選取與讀取）；粒子用 Canvas 2D 自己算（輕量）
- 引力：每幀對範圍內 body `applyForce`，力 ∝ 質量倒數，讓輕物件更明顯
- 拖曳：`Matter.MouseConstraint`，或自己用 Pointer Events 接
- 傾斜：`deviceorientation` 的 beta/gamma 映射到 `engine.gravity.x/y`

## 專屬陷阱
- iOS 13+ 的 `DeviceOrientationEvent.requestPermission()` 必須在使用者手勢（點按鈕）裡呼叫，且只在 HTTPS／localhost 有效；被拒時退回觸控模式
- Android 不需權限但部分瀏覽器方向軸不同：加校正並限制最大傾角
- 物件太多或太小會穿牆：牆加厚、限制最大速度、物件數控制在 30–60
- 拖曳時頁面跟著捲動 → `touch-action: none`
- 視窗縮放後牆的位置沒更新，東西掉出畫面：`resize` 時重建邊界
- 「掉落」動態對部分使用者不適：低動態模式下物件固定排好，只保留拖曳

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「重力感應」首頁，品牌名 {品牌名}，主標 {主標}，關鍵數字 {數字，例如 2026}。

視覺：
- 米白底、黑色物件、螢光綠點綴 {#3BFF6A}
- 游標是小圓引力源，外圍淡淡的引力範圍圈
- 物件：主標拆成可拖曳的大字、3–5 張實驗卡片 {卡片內容}、一顆由小數字粒子組成的 {數字} 球

物理：
- 用 Matter.js（cdnjs 固定版本）；物件分輕／中／重：輕的漂浮、中的被吸、重的落地碰撞回彈
- 游標引力：範圍內物件受力，輕物件更明顯
- 拖曳可丟擲；丟到數字球會把粒子撞散，之後慢慢聚回
- 右下「重置」讓物件歸位

手機：
- 「啟用傾斜」按鈕：在點擊事件內呼叫 DeviceOrientationEvent.requestPermission（iOS），成功後以傾斜控制重力
- 權限被拒或不支援：頁內提示，改用一般觸控模式（拖曳＋點擊產生引力）
- 物件數量減半；Pointer Events；可拖曳區 touch-action: none；100dvh

技術約束：
- 文字與卡片是 DOM 元素跟隨物理 body（可讀可選），粒子用 Canvas
- 視窗縮放時重建牆；限制最大速度避免穿牆
- prefers-reduced-motion 或頁內「低動態」開關：物件固定排好不掉落，只保留拖曳

不可做：不要深色宇宙星空背景；不要物件多到擋住主標；不要開頁就請求傾斜權限。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：重力實驗場（游標是引力源，物件會漂浮、墜落、碰撞）
- **情緒關鍵字**：好玩、實驗、可觸摸、輕盈
- **配色**：米白 #F3F0E8；黑 #111111；螢光綠 #3BFF6A
- **材質**：紙卡、實心幾何、數字點陣
- **版面**：單屏實驗場；主標拆字散落；卡片與數字球分布其中；手機同構
- **核心互動**：游標吸起輕物件；拖曳丟擲撞散數字球；手機傾斜
- **一句話流程**：進場見物件落地 → 游標吸起 → 丟字撞球 → 傾斜手機 → 重置
- **不可做**：宇宙星空、物件擋主標、開頁即要權限
- **要交付的畫面**：靜止首屏、引力吸起中、碰撞瞬間、手機傾斜提示畫面
```
