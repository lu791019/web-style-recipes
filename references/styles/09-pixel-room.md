# 09 像素房間（Pixel Room）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：敘事場景
- **適合用途**：個人作品集、獨立遊戲／創作者首頁、工作室介紹、帶彩蛋的履歷網站

## 視覺特徵清單
- 深夜像素公寓的剖面圖，看得到好幾個房間
- 房間對應網站區塊：About、Projects、Notes、Contact
- 可點物件：電腦（作品）、日記本（自我介紹）、冰箱便利貼（筆記）、電話（聯絡）
- 點了跳出復古遊戲對話框（像素邊框、逐字打出）
- 午夜藍、灰紫、奶油黃、霓虹青、暖橘燈光
- 窗外即時時鐘、環境小動畫（閃爍燈、雨、貓尾巴）
- 探索進度（例如 3/8），全找到後解鎖秘密房間

## 一句話流程
進場看到深夜公寓剖面 → 滑鼠或方向鍵移動游標 → 點物件跳出對話框讀內容 → 探索進度累積 → 解鎖秘密房間

## 迭代順序
1. 剖面構圖與房間配置（先用色塊確定位置）
2. 物件與對話框（內容先可讀）
3. 鍵盤操作與焦點順序
4. 像素美術細節、燈光
5. 環境動畫與即時時鐘
6. 探索進度、秘密房間、手機

## 技術棧
- 場景：CSS 網格＋像素圖（SVG `shape-rendering: crispEdges` 或小 PNG 放大＋`image-rendering: pixelated`）
- 物件：真正的 `<button>`，有 `aria-label`，可 Tab 聚焦，Enter／Space 觸發
- 對話框：`<dialog>` 或 role=dialog，逐字打字效果可按鍵跳過，Esc 關閉、焦點回到物件
- 進度：Set 記錄已探索物件，存 localStorage（try/catch）
- 時鐘：`setInterval` 每秒更新，像素字體

## 專屬陷阱
- 物件用 div＋click 會讓鍵盤和讀屏器無法操作 → 一律 button
- 像素圖放大不設 `image-rendering: pixelated` 會糊掉
- 放大倍率非整數時像素會不均：用整數倍縮放，或 `ResizeObserver` 算最接近的整數倍
- 逐字打字太慢會讓人煩：預設約 30ms／字，點擊或任意鍵直接全顯
- 手機剖面太小點不到：手機改成一次顯示一間房、左右滑換房，物件點擊區至少 44px
- 內容（作品、聯絡方式）不能只藏在遊戲裡：提供一個「略過遊戲，直接看內容」的連結

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「像素房間」個人首頁，主人 {名字}，職稱 {職稱}。

視覺：
- 深夜像素公寓剖面，四個房間：About、Projects、Notes、Contact
- 配色：午夜藍、灰紫、奶油黃、霓虹青、暖橘燈光
- 窗外有即時時鐘（像素字體），環境小動畫：{例如閃爍檯燈、窗外下雨、貓尾巴擺動}

互動：
- 可點物件：電腦→作品列表 {作品}、日記本→自我介紹 {介紹}、冰箱便利貼→筆記 {筆記}、電話→聯絡方式 {聯絡}，另藏 4 個小彩蛋物件
- 點擊跳出復古遊戲對話框：像素邊框、逐字打出（約 30ms／字，按任意鍵全顯）、Esc 關閉
- 右上探索進度（如 3/8）；全部找到後解鎖秘密房間 {秘密內容}；進度存 localStorage（try/catch）

技術約束：
- 物件都是 <button>（含 aria-label），可 Tab 移動、Enter 開啟；對話框關閉後焦點回原物件
- 像素圖以整數倍放大、image-rendering: pixelated
- 手機：一次顯示一間房，左右滑或按鈕換房；點擊區至少 44px；Pointer Events
- 頁面頂端提供「略過遊戲，直接看內容」連結
- prefers-reduced-motion：停環境動畫、對話框文字直接全顯

不可做：不要做成需要打怪或計時的遊戲；不要用高解析插畫混像素；不要把聯絡方式只藏在彩蛋裡。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：深夜像素公寓（可探索的遊戲式個人首頁）
- **情緒關鍵字**：溫馨、好奇、深夜、私密感
- **配色**：午夜藍 #141B3A；灰紫 #4B4466；奶油黃 #F6E7B0；霓虹青 #3EE6E0；暖橘燈 #F59A3C
- **材質**：像素點陣、暖色燈光暈染、復古遊戲對話框邊框
- **版面**：桌機單屏公寓剖面；手機一次一房、左右切換
- **核心互動**：點物件跳對話框；收集探索進度解鎖秘密房間
- **一句話流程**：進場看公寓 → 點電腦看作品 → 點日記讀介紹 → 集滿進度 → 開秘密房間
- **不可做**：戰鬥／計時遊戲、高解析插畫混搭、內容只藏在彩蛋
- **要交付的畫面**：桌機公寓全景、對話框開啟、秘密房間、手機單房畫面
```
