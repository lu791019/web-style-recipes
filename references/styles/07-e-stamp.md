# 07 電子郵票（E-Stamp）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：單一物件隱喻
- **適合用途**：品牌故事頁、旅行／地方品牌、新年或活動祝福頁、時光膠囊類活動（例：寄給未來的訊息）

## 視覺特徵清單
- 郵票齒孔邊（鋸齒圓孔）
- 面額數字、發行單位小字
- 圓形郵戳（日期＋地名）蓋在郵票一角
- 紙張纖維顆粒、印刷網點
- 油墨套色微微偏移（套印不準的錯位感）
- 米白紙、郵務深藍、郵戳紅

## 一句話流程
進場看到一張大郵票 → 切換郵票插圖 → 點擊蓋上郵戳（有壓下動畫）→ 在右側輸入「給未來的訊息」與目的地 → 生成一張自己的小郵票並可下載

## 迭代順序
1. 單張郵票的質感：齒孔、紙紋、網點、套色偏移
2. 100vh 三欄版面：左品牌介紹、中大郵票、右小郵票產生器
3. 點擊蓋郵戳（隨機微旋轉、墨色不均）
4. 插圖切換
5. 產生器：輸入→即時預覽→下載 PNG
6. 手機版改直排、減少動態

## 技術棧
- 齒孔：CSS `mask` 用 radial-gradient 重複圓孔，或 SVG 路徑
- 網點：小點 radial-gradient 平鋪＋`mix-blend-mode: multiply`
- 套色偏移：同一插圖兩層（主色與陰影色）位移 1–2px
- 郵戳：SVG 圓形文字路徑（`textPath`）＋日期；點擊時從放大到落定、加墨跡雜訊
- 下載：把郵票畫到 canvas（或 SVG 序列化成圖片）→ `toBlob`

## 專屬陷阱
- 三欄塞進 100vh 在矮螢幕會擠：用 `clamp()` 控郵票尺寸，桌機最小高度不足時允許內部捲動
- CSS mask 齒孔在匯出 PNG 時不會被 canvas 吃到：匯出要用 canvas 重畫齒孔，或全程用 SVG
- SVG 轉圖片時外部字型不會帶進去：匯出用系統字或把字型轉 base64 內嵌
- 使用者輸入要轉義後再放進 SVG／HTML，避免注入
- 郵戳每次都蓋在同一點、同角度會很假：位置與角度加小幅隨機

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「電子郵票」首頁，品牌名 {品牌名}，故事主題 {主題，例如：寄給未來的訊息}。

視覺：
- 米白紙底，帶纖維顆粒與印刷網點；郵務深藍為主色，郵戳紅點綴
- 郵票有齒孔邊、面額 {面額}、發行單位小字；插圖兩層套色微微錯位
- 圓形郵戳：環形文字 {地名} ＋ 日期

版面（100dvh 單屏三欄）：
- 左：品牌介紹與故事 {文案}
- 中：一張大郵票，下方切換插圖（3 款：{插圖主題}）；點擊郵票蓋上郵戳，郵戳有壓下動畫、位置角度微隨機
- 右：小郵票產生器——輸入訊息、目的地、選插圖 → 即時預覽 → 下載 PNG

技術約束：
- 齒孔用 SVG 或 canvas 繪製，確保匯出 PNG 時齒孔、郵戳都在
- 使用者輸入要轉義；字數上限並即時顯示
- 手機：三欄改直排（介紹→大郵票→產生器），允許捲動；按鈕至少 44px；Pointer Events
- prefers-reduced-motion：郵戳直接出現，不做壓下動畫

不可做：不要做成現代卡片 UI；不要高飽和漸層；不要讓三欄在桌機出現頁面捲軸。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：電子郵票（老郵票印刷質感＋可自製郵票）
- **情緒關鍵字**：溫暖、珍藏、寄託、慢
- **配色**：米白 #F4EEDF；郵務深藍 #1E3A6B；郵戳紅 #C23B2E；墨黑
- **材質**：紙纖維、網點、套色偏移、郵戳墨跡
- **版面**：桌機單屏三欄（介紹／大郵票／產生器）；手機直排可捲動
- **核心互動**：點擊蓋郵戳；輸入訊息即時生成自己的郵票
- **一句話流程**：進場見大郵票 → 換插圖 → 蓋郵戳 → 寫訊息與目的地 → 下載我的郵票
- **不可做**：現代卡片 UI、高飽和漸層、乾淨無紋理的扁平風
- **要交付的畫面**：桌機首屏三欄、蓋郵戳瞬間、產生器預覽、手機直排
```
