# 03 音檔可視化（Audio Visualizer／聲紋）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：Canvas 動態場
- **適合用途**：音樂人／Podcast 作品集、聲音品牌、發表會倒數頁、錄音或語音產品首頁

## 視覺特徵清單
- 純黑背景
- 冷白色短點（不是長條）一顆顆堆成柱
- 柱子以水平中線上下對稱
- 整片由右往左捲動，新的一欄從右邊長出
- 舊欄漸暗，像示波器的磷光殘影
- 四角細線框；底部小號等寬讀數：RMS（dBFS）、峰值頻率（Hz）、BPM

## 一句話流程
進場看到標示「模擬訊號」的聲紋已在流動 → 選音源（示範音軌／上傳或拖放音檔／麥克風）→ 聲紋即時反應 → 讀數跳動 → 暫停可停格

## 迭代順序
1. **先調點**：點的大小、間距、亮度——這決定整體質感，其他都是後話
2. 對稱柱與捲動速度
3. 殘影衰減曲線
4. 讀數（RMS、峰值頻率、BPM）
5. 三種音源切換與拖放
6. 手機、權限被拒、減少動態

## 技術棧
- Web Audio：`AudioContext` → 音源節點 → `AnalyserNode`（`fftSize` 1024–2048）→ 輸出
- 示範音軌：用 `OscillatorNode`＋`GainNode` 包絡即時合成節拍與旋律，免帶音檔
- 上傳：`<input type=file>`＋拖放，`decodeAudioData` 或 `<audio>`＋`createMediaElementSource`
- 麥克風：`getUserMedia({ audio: true })` → `createMediaStreamSource`（不要接到 destination，避免回授）
- 繪製：Canvas 2D；每幀把畫布左移一欄（`drawImage` 自己畫自己）再畫新欄；殘影用半透明黑覆蓋
- 讀數：時域資料算 RMS→dBFS；頻域找最大 bin 換算 Hz；BPM 用能量峰值間隔粗估

## 專屬陷阱
- 瀏覽器要求使用者手勢後才能啟動 AudioContext：開頁的模擬訊號要用純 JS 假資料畫，按下按鈕後才 `resume()` 真的音訊
- 麥克風接到 destination 會嘯叫
- 頻率是線性分佈，低頻擠在左邊幾個 bin：柱高取對數頻帶分組才好看
- 讀數每幀更新會閃到看不清，節流到約 10 次／秒並平滑
- BPM 估算不準要誠實標「約」，或只在示範音軌顯示已知 BPM

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「音檔可視化」首頁，品牌名 {品牌名}，副標 {副標}。

視覺：
- 純黑底；冷白色小方點一顆顆堆成柱，以水平中線上下對稱
- 整片由右往左捲動，新欄從右邊出現；舊欄逐漸變暗，像磷光殘影
- 四角細線框；底部一排小號等寬讀數：RMS（dBFS）、峰值頻率（Hz）、BPM

流程：開頁就有聲紋在流動，角落標示「SIMULATED／模擬訊號」→ 使用者選音源 → 聲紋即時反應。

音源（三選一，按鈕切換）：
1. 示範音軌：用 OscillatorNode 即時合成一段有鼓點與旋律的循環，不帶外部檔案
2. 上傳或拖放音檔
3. 麥克風（不要接到喇叭，避免回授）

技術約束：
- Web Audio AnalyserNode；柱高用對數頻帶分組；讀數節流約 10 次／秒並平滑
- 開頁的模擬訊號用 JS 假資料畫；使用者按下後才建立／resume AudioContext
- 麥克風需 localhost 或 HTTPS；權限被拒或沒有麥克風時頁內說明，並建議改用示範音軌或上傳
- 手機：點的欄數減半、按鈕在底部、Pointer Events、100dvh
- prefers-reduced-motion：停止捲動，改成原地更新的對稱頻譜；頁內有動態開關

不可做：不要彩虹漸層長條；不要圓形放射狀頻譜；不要預設自動播放有聲音。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：示波器式聲紋（點陣、中線對稱、磷光殘影）
- **情緒關鍵字**：冷靜、精準、夜間錄音室、專注聆聽
- **配色**：純黑 #000；冷白 #E8F0FF；讀數低透明白；無其他彩色
- **材質**：發光點、磷光殘影、細線框
- **版面**：單屏，聲紋佔中段全寬；品牌名在上、讀數在下；手機同構
- **核心互動**：切換音源，聲紋即時長出並向左流走
- **一句話流程**：進場看模擬聲紋 → 選音源 → 聲紋反應 → 看讀數 → 停格
- **不可做**：彩虹長條、圓形放射頻譜、霓虹多色
- **要交付的畫面**：首屏模擬訊號、示範音軌播放中、停格狀態、手機首屏
```
