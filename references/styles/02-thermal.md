# 02 熱感應（Thermal Camera）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：Canvas 動態場
- **適合用途**：科技或研究型品牌首頁、作品集 Hero、新品預告、需要「一眼記住」的實驗頁

## 視覺特徵清單
- 近黑的深藍背景（冷區）
- 熱點中心發白，向外依溫度色階漸層（彩虹或鐵虹），邊緣有柔光暈
- 主角 1–2 個去背輪廓（貓、蝴蝶等），以熱像方式呈現
- HUD：四角對焦框、細掃描線、閃爍 REC、側邊 16–38°C 溫度刻度
- 跟隨主角的鎖定框，旁邊即時溫度讀數（等寬字）

## 一句話流程
進場看到熱像主角在冷背景裡發亮 → 移動游標沿路加熱 → 點擊投下一團熱源 → 主角飛過留下逐漸冷卻的殘影 → 切換色盤（鐵虹／彩虹／白熱）

## 迭代順序
1. 色階對照：先把溫度值→顏色的 LUT 調對（黑→深藍→紫→紅→橘→黃→白）
2. 熱場物理：擴散速度與冷卻速度，決定「殘影能留多久」
3. 主角：去背 PNG 的亮度反推成熱度，蓋到熱場上
4. 游標加熱與點擊投熱的半徑、強度
5. HUD 與鎖定框
6. 色盤切換、手機與減少動態

## 技術棧
- Canvas 2D；熱場用 `Float32Array` 低解析網格（約 200–300 欄，列數依比例），每幀擴散＋乘冷卻係數
- 渲染：網格值查 256 色 LUT 寫進 `ImageData`，畫到小 canvas，再以 CSS 放大（平滑插值看起來更像熱像）
- 主角：去背 PNG 畫到離屏 canvas，`getImageData` 取亮度 × alpha 當熱源；路徑用 Lissajous 或貝茲曲線飛行
- HUD 用 DOM／SVG 疊在上層，`pointer-events: none`

## 專屬陷阱
- **跟隨標籤撞到溫度刻度**（2026-10-18 實測）：鎖定框旁的溫度／名稱標籤跟著主角移動，靠近右緣時會壓到右側刻度。標籤要做邊界偵測：離右緣或刻度太近就翻到框的左側，並給刻度預留不可進入的安全區。
- 去背 PNG 在 file:// 下會污染 canvas → 本機伺服器或 base64（見 pitfalls #2）
- 熱擴散只有擴散沒有冷卻，畫面會整片變白；冷卻係數約 0.97–0.99/幀，要隨幀率校正（用 delta time）
- 主角若每幀「寫入」熱度而不是「取最大值」，會越疊越亮爆白
- 放大後若用 pixelated 會像像素畫，失去熱像的柔感；要像素風才用
- 溫度讀數要從網格反算（值→°C 線性對映到 16–38），不要亂數跳

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「熱感應攝影機」風格首頁，品牌名 {品牌名}，主標 {主標}。

視覺：
- 背景近黑深藍；熱點中心白、往外依色階變黃→橘→紅→紫→深藍，帶柔光暈
- 主角：{主角，例如一隻貓與一隻蝴蝶}，用去背 PNG（我會提供 {檔名}；沒提供就用 canvas 畫的簡單剪影）把亮度換成熱度
- HUD：四角對焦框、細掃描線、左上閃爍紅點 REC、右側 16–38°C 溫度刻度；鎖定框跟著主角，旁邊等寬字即時溫度

互動：
- 游標移動處加熱（小半徑），點擊投下大團熱源
- 主角沿平滑曲線飛行，經過處留殘影並逐漸冷卻
- 右下按鈕切換色盤：鐵虹／彩虹／白熱

技術約束：
- Canvas 低解析網格（約 240 欄）做擴散＋冷卻，用 delta time 校正，畫到小 canvas 後 CSS 放大（平滑）
- 溫度→顏色用 256 階預算 LUT
- 需在 localhost（npx serve）下開，避免讀圖像素失敗；或圖片用 base64 內嵌
- 手機：網格降到約 120 欄、觸控拖曳即加熱、點擊投熱；Pointer Events；100dvh 單屏
- prefers-reduced-motion：主角停在定點、熱場只在使用者互動時更新；頁內有動態開關
- 分頁隱藏時暫停迴圈；開頁即有熱像畫面，不要等互動

不可做：不要用真的鏡頭；不要做成綠色夜視；HUD 不要擋住主標。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：熱感應攝影機（紅外熱像畫面＋取景 HUD）
- **情緒關鍵字**：神秘、科技、生命感、觀察中
- **配色**：近黑深藍 #05081A 底；熱度色階 深藍→紫→紅→橘→黃→白；HUD 用低透明白
- **材質**：柔光暈、細掃描線、輕微雜訊
- **版面**：單屏全幅熱像；主標壓在冷區；HUD 貼四角；手機直式同構
- **核心互動**：游標走過留下熱痕；點擊投下熱源；主角飛過留冷卻殘影
- **一句話流程**：進場見發光主角 → 游標加熱 → 點擊投熱 → 看殘影冷卻 → 換色盤
- **不可做**：綠色夜視、真實照片質感、HUD 擋住主標
- **要交付的畫面**：首屏靜態、游標加熱中、點擊投熱瞬間、三種色盤對照、手機首屏
```
