# 04 白板便利貼（Whiteboard & Sticky Notes）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：單一物件隱喻
- **適合用途**：個人首頁「關於我」、工作坊／腦力激盪頁、團隊介紹、課程留言牆

## 視覺特徵清單
- 淡灰牆面，中間一塊白板，白板上有淡淡點點格線
- 五種粉彩便利貼（黃、粉、藍、綠、橘），各自微微傾斜
- 便利貼頂端一條半透明紙膠帶，兼當拖曳把手
- 手寫字體；角落散落星星貼紙
- 拖起來時便利貼轉正、陰影加深，像被手拿起

## 一句話流程
進場看到白板上已貼好幾張自我介紹便利貼 → 拖曳整理 → 雙擊空白處新增一張並打字 → 用畫筆或螢光筆圈重點 → 貼星星 → 重新整理後內容還在

## 迭代順序
1. 白板與便利貼的靜態樣子（顏色、傾斜、膠帶、陰影）
2. 拖曳手感（拿起轉正、放下回到微傾斜）
3. 雙擊新增與編輯文字
4. 工具列：移動、便利貼、畫筆、螢光筆、橡皮擦、貼紙
5. 復原／重做、清空確認、localStorage 保存
6. 手機（工具列移底部）、減少動態

## 技術棧
- 便利貼：DOM 元素＋`contenteditable`；位置用 transform
- 筆跡：一張全白板 canvas，筆畫存成點陣列（向量），重繪時逐筆畫
- 螢光筆：`globalCompositeOperation = 'multiply'`、粗筆、半透明，疊色才會像真的
- 橡皮擦：整筆擦——點擊命中某筆畫的範圍就刪掉整筆，不做像素擦
- 狀態：`{ notes: [], strokes: [], stickers: [] }`，每次變更推入歷史堆疊（復原／重做），並寫入 localStorage

## 專屬陷阱
- **手機上便利貼被裁切、互相重疊**（2026-10-18 實測，390 寬）：預設便利貼用桌機絕對座標放置，窄螢幕右側被切掉。預設內容的位置要用白板寬高的比例換算，並在載入與 resize 時把超出邊界的便利貼收回畫面內。
- **手機底部工具列放不下**（同上）：工具超過螢幕寬度時最右邊的被切掉。窄螢幕改成可橫向捲動、只顯示圖示，或把較少用的工具（復原、重做、清空）收進「更多」。
- 拖曳用滑鼠事件在手機失效、拖曳時頁面捲動 → Pointer Events＋`setPointerCapture`＋`touch-action: none`
- `contenteditable` 裡雙擊會選字，跟「雙擊新增」衝突：只有雙擊白板空白處才新增
- 狀態直接改舊物件，復原會壞 → 每次產生新狀態物件
- 清空不要用 `confirm()`，做頁內確認小卡（「確定清空？／取消」）
- localStorage 讀寫包 try/catch；壞資料時回預設範例
- 單屏不捲動：白板塞進 100dvh，手機工具列固定在底部且不擋便利貼

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「白板便利貼」首頁，主人是 {名字}，用途 {用途}。

視覺：
- 淡灰牆面，中央白板帶淡點點格線
- 五種粉彩便利貼（黃、粉、藍、綠、橘），隨機微傾斜 ±3°，頂端半透明紙膠帶
- 手寫字體；角落有星星貼紙
- 預設貼好 4–6 張：{預設內容，例如自我介紹、作品、聯絡方式}

互動：
- 拖曳紙膠帶移動便利貼：拿起時轉正、陰影加深，放下恢復微傾斜
- 雙擊白板空白處新增便利貼並直接打字
- 工具列：移動、便利貼、畫筆、螢光筆（multiply 疊色）、橡皮擦（一次擦掉整筆）、星星貼紙
- 復原／重做（Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z 與按鈕）、清空（頁內確認卡，不用 confirm）

技術約束：
- 狀態不可變更新，推入歷史堆疊；存 localStorage（讀寫包 try/catch，失敗時頁面照常並提示不會保存）
- Pointer Events＋setPointerCapture，可拖曳區 touch-action: none
- 單屏不捲動（100dvh）；手機工具列移到底部，按鈕至少 44px
- prefers-reduced-motion：拿起／放下不做旋轉動畫

不可做：不要做成 Trello 式看板欄位；不要純白無格線；不要彈出 alert/confirm。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：白板便利貼（會議室白板，貼滿手寫便利貼）
- **情緒關鍵字**：親切、手作、腦力激盪、輕鬆
- **配色**：淡灰牆 #E9E9EC、白板 #FFFFFF；便利貼 黃 #FFF3A3、粉 #FFD1DC、藍 #CDE7FF、綠 #D5F5C8、橘 #FFD9B0
- **材質**：紙張、半透明紙膠帶、淡點點格線、柔和投影
- **版面**：單屏；白板佔滿中央；工具列桌機在左側／手機在底部
- **核心互動**：拖曳便利貼（拿起轉正）、雙擊新增、螢光筆圈重點
- **一句話流程**：進場看白板 → 拖曳整理 → 新增一張 → 圈重點貼星星 → 重整後還在
- **不可做**：看板欄位、純白無格線、科技感漸層
- **要交付的畫面**：首屏預設白板、拖曳中、畫筆標註後、手機首屏（底部工具列）
```
