# 11 等距線稿互動圖（Hairline）

> 出處：Lucas Markes〈hairline〉，`@lucasmarkes/hairline`（https://hairline.lucasmarkes.com/figures ，v0.5.1，36 張圖分 8 類）。本檔為改寫整理。**實作交給已安裝的 `hairline-create`／`hairline-adopt` skill**（`~/.agents/skills/`，與上游一致），本檔只管什麼時候用、長什麼樣、怎麼放進頁面。

- **分類**：單一物件隱喻
- **適合用途**：產品或技術服務的 hero 小圖、功能區塊的說明圖、空狀態（empty state）、把公司 logo 變成會動的線稿；尤其是「抽象概念要一眼看懂」的技術題材（資料、權限、連線、程式碼）

## 視覺特徵清單
- 等距視角（沒有消失點）的單色細線圖，一張只畫一個物件：鍵盤、轉盤、保險箱、路由器、終端機、抽屜
- 筆畫是唯一的強調：靜止時只有一處亮線告訴你眼睛該看哪
- 不填色、不漸層、不陰影、不加粗；只有亮線、暗線、點三種狀態
- 靜止狀態是設計過的：零件有高低、有傾斜，不是平整的格子
- 游標靠近時，物件做出跟它意義相符的「回應手勢」：保險箱門開一條縫、卡片依距離依序掀起、地形隆起
- 動作依離游標的距離錯開（每件 30～60ms），讀起來是一個手勢
- 小尺寸也成立（240px 縮圖仍看得懂）

## 一句話流程
看到一個靜止但有表情的線稿物件 → 游標靠近 → 物件用一個貼合意義的手勢回應（亮線移到被指的那個零件）→ 游標離開，回到設計過的靜止姿勢

## 迭代順序
1. **選物件與概念**：這個區塊要講什麼，一個物件能不能講完（不能就拆成兩張圖，不要一張畫兩件事）
2. **靜止姿勢**：還沒互動時就要說得出它是什麼
3. **回應手勢**：一種就好，跟概念綁在一起（「權限」＝門開縫，不是門轉圈）
4. **觸及範圍**：最大動作也不能散架、不能出框
5. **放進頁面**：線色吃頁面的 token，尺寸與留白配合版面
6. **降級**：觸控沒有 hover，給點擊或捲動觸發；reduced-motion 直接停在一個好看的中間姿勢

## 技術棧
- `hairline-create`：從一個想法畫一張新圖，產出單一 HTML（內含 kernel）；`look.mjs` 會截 8 張圖自檢
- `hairline-adopt`：手上有 SVG（icon、logo、插圖）時，把它重建成 Hairline 線稿並加上手勢
- 嵌入：把產出的 `<name>.js` 與 kernel 放進頁面，或直接 iframe 單一 HTML

## 專屬陷阱
- **把它當插畫用**：它是「一個概念＝一個物件＝一個手勢」，塞一整個場景就失去可讀性
- **自己加顏色或陰影**：hairline 規則明定筆畫是唯一的強調；要配合品牌色，只改線色 token，不加填色
- **靜止時是一片平整格子**：第一眼什麼都看不出來，等於沒有圖
- **多張圖同時都在動**：一個區塊只讓一張圖回應游標，其他維持靜止
- **自己寫 requestAnimationFrame**：動作要走 kernel 的 `register(stage, tick)`，畫面外會自動停，省電
- 共通陷阱見 `../pitfalls.md`（觸控、reduced-motion、手機效能）

## prompt 範本
```
/hairline-create {物件與概念：例如「一個保險箱，代表我們幫客戶把資料權限收緊」}
- 靜止：{哪個零件有一處亮線}
- 回應：游標靠近時 {手勢：門開一條縫、內部抽屜依距離依序拉出}
- 放在：{頁面與區塊}，寬約 {px}，線色用 {頁面 token 或 hex}
- 觸控：{點擊觸發／捲動進場觸發}；reduced-motion 停在 {中間姿勢}
```
已有 SVG（例如公司 logo）時改用：`/hairline-adopt {檔案.svg} {游標靠近時它做什麼}`

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名} 的 Hairline 線稿圖

- **風格**：等距單色細線圖，一張一物件（參考：hairline.lucasmarkes.com/figures 的 Vault、Terminal、Router）
- **參考經典**：ustwo《Monument Valley》（2014）的等距構成；工程製圖的等距投影
- **情緒關鍵字**：精準、安靜、會回話
- **配色**：只用 {線色} 與它的暗階；背景 {頁面底色}；不填色
- **材質**：無；只有線與點
- **版面**：{區塊位置}，物件置於 {左／右}，旁邊是 {標題與說明}
- **核心互動**：游標靠近時 {手勢}
- **一句話流程**：靜止有表情 → 游標靠近 → 物件以手勢回應 → 回到靜止
- **不可做**：填色、漸層、陰影；一張圖畫一整個場景；靜止時是平整格子
- **要交付的畫面**：靜止、回應中、手機縮圖（240px）
```
