# 06 萬花筒（Kaleidoscope）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：Canvas 動態場（可用 WebGL）
- **適合用途**：精品／香氛／珠寶品牌首頁、藝術展或音樂祭 Hero、攝影作品集

## 視覺特徵清單
- 12／16／24 面鏡像切片構成的圓形圖騰
- 緩慢自轉，滑鼠移動帶出視差與折射偏移
- 紋理來源：花朵、玻璃帷幕建築、晶體
- 深黑底，玻璃藍、莓果紅、金色點綴
- 精品感高對比標題（細襯線或極細無襯線），導覽極簡
- 往下捲動時圖騰動態逐漸減弱、退成背景

## 一句話流程
進場看到緩緩旋轉的萬花筒 → 移動滑鼠讓鏡面折射偏移 → 切換切片數或紋理 → 往下捲，動態漸弱、內容浮上來

## 迭代順序
1. 單一切片的鏡像正確（相鄰切片要對接無縫）
2. 紋理選擇與取樣範圍
3. 旋轉速度與滑鼠視差強度
4. 標題排版與導覽
5. 捲動遞減、切片數／紋理切換
6. 手機降級、減少動態

## 技術棧
- Canvas 2D 版：對每個切片 `save → rotate(i·θ) → 偶數片 scale(1,-1) → clip 三角形 → drawImage 紋理 → restore`
- WebGL 版（較順）：片段著色器把極座標角度對 θ 取模並鏡射，再取樣紋理；可加色散（RGB 三通道偏移）做折射
- 紋理：內嵌或本機圖片；沒有素材時用程式生成的花瓣／晶體圖形
- 捲動：`scroll` 進度映射到旋轉速度、視差強度、透明度

## 專屬陷阱
- 切片數若非偶數，鏡像接縫會錯位；只用偶數（12／16／24）
- Canvas 2D 每幀畫 24 次大圖很吃效能：先把一片畫到離屏 canvas，再旋轉複製
- 圖片在 file:// 下當 WebGL 紋理會被擋 → 本機伺服器或 base64
- 高 DPR 螢幕全解析度跑 shader 很燙：限制 `devicePixelRatio ≤ 2`，手機 1.5
- 色散與模糊在手機上關掉；捲動到底時停止迴圈省電
- 旋轉圖騰對前庭敏感者不友善，reduced-motion 必須靜止

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「萬花筒」精品風首頁，品牌名 {品牌名}，標語 {標語}。

視覺：
- 深黑底；畫面中央一個大型萬花筒圖騰，{12/16/24} 面鏡像切片，緩慢自轉
- 紋理來源：{花朵／玻璃建築／晶體}；我會提供圖片 {檔名}，沒有就用程式生成的花瓣與晶體圖形
- 點綴色：玻璃藍、莓果紅、金
- 標題高對比、精品感（細襯線大字），導覽列極簡只有 3–4 個連結

互動：
- 滑鼠移動帶出視差與折射偏移（WebGL 可加輕微 RGB 色散）
- 右下小控制：切換切片數（12/16/24）、切換紋理
- 往下捲動：旋轉與視差逐漸減弱，圖騰變暗退成背景，下方內容 {內容區塊} 浮上來

技術約束：
- 優先 WebGL 片段著色器；不支援時退回 Canvas 2D（離屏畫一片再旋轉複製）
- devicePixelRatio 上限 2（手機 1.5）；分頁隱藏與捲出視窗時暫停
- 手機：關閉色散與模糊、降解析度，用觸控拖曳代替滑鼠視差
- prefers-reduced-motion：圖騰靜止，只有使用者拖曳時才轉
- 圖片需 localhost（npx serve）或 base64，避免紋理被擋

不可做：不要迷幻霓虹彩虹；不要讓圖騰蓋住標題可讀性；不要加大量浮動粒子。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：精品萬花筒（多面鏡像切片，緩慢旋轉）
- **情緒關鍵字**：奢華、迷人、凝視、靜謐
- **配色**：深黑 #07070A；玻璃藍 #5FA8D3；莓果紅 #B0244B；金 #C9A24A
- **材質**：玻璃折射、晶體切面、花瓣絲絨
- **版面**：首屏中央大圖騰＋高對比標題；極簡導覽；往下捲圖騰退為背景
- **核心互動**：滑鼠帶出折射偏移；捲動時動態漸弱
- **一句話流程**：進場見旋轉圖騰 → 移動滑鼠看折射 → 換切片數 → 往下捲看內容
- **不可做**：迷幻霓虹、粒子滿天飛、標題被圖騰吃掉
- **要交付的畫面**：首屏、滑鼠偏移中、三種切片數對照、捲動後的內容區、手機首屏
```
