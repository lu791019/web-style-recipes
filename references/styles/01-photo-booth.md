# 01 復古自拍亭（Photo Booth）

> 出處：AI郵報〈10 種 Vibe Coding 網站設計靈感〉，Joanna Chang，2026-10-14，https://www.aiposthub.com/vibe-coding-website-ideas/ 。本檔為改寫整理，非原文。

- **分類**：相機類
- **適合用途**：活動報到頁、婚禮／派對紀念頁、品牌快閃、個人作品集的「玩一下」入口

## 視覺特徵清單
- 拉絲銀色金屬機身，邊緣有鉚釘或接縫
- 深紅絨布簾，有垂墜皺褶與陰影
- 黑白棋盤格地板，帶透視
- 機身上方一塊會亮的招牌燈（燈泡框或霓虹字）
- 成品：直式四格底片條，黑白高對比＋底片顆粒、白邊
- 倒數數字用大號復古字體

## 一句話流程
進入場景 → 點擊拉開布簾 → 鏡頭開啟、倒數 3、2、1 → 白光一閃 → 連拍四張 → 吐出黑白四格底片條 → 下載或重拍

## 迭代順序
1. 場景骨架：機身、布簾、地板的比例與透視
2. 布簾開合：先用兩張背景圖（關簾／開簾）淡入切換，掩蓋兩圖的細微差異，比做布料動畫穩
3. 倒數與閃光的節奏（閃光約 150ms 白層淡出）
4. 四格成品的濾鏡：灰階、拉高對比、疊顆粒
5. 招牌燈閃爍、音效等裝飾
6. 手機版與權限被拒

## 技術棧
- `getUserMedia({ video: { facingMode: 'user' } })` 接 `<video>`
- 拍照：把 video 畫到 canvas，`filter: grayscale(1) contrast(1.6)` 或逐像素處理，再疊雜訊
- 合成四格：一張直式 canvas 依序畫四格＋白邊＋日期字樣，`toBlob` 下載
- 場景圖：CSS 繪製或兩張背景圖，用 opacity 過渡切換

## 專屬陷阱
- 前鏡頭畫面是鏡像的：預覽要 `scaleX(-1)`，存檔時決定要不要翻回來，前後一致
- 連拍間隔太短會拍到同一個表情，每張間隔約 1–1.5 秒並給小倒數
- 兩張背景圖尺寸、構圖必須一致，否則切換時會跳；切換用淡入，不要硬切
- canvas 合成時 video 尚未 `loadedmetadata` 會拿到 0×0，要等就緒
- 拍完要 `track.stop()` 關鏡頭，不然鏡頭燈一直亮

## prompt 範本
```
做一個單一 HTML 檔（內嵌 CSS 與 JS）的「復古自拍亭」互動首頁，品牌名 {品牌名}，用途是 {用途}。

視覺：
- 拉絲銀色金屬機身置中，上方有會亮的招牌燈，寫著 {品牌名}
- 機身開口掛深紅絨布簾，有皺褶陰影
- 地面是有透視的黑白棋盤格
- 倒數數字用大號復古字體

流程：進場 → 點「拉開布簾」→ 開鏡頭 → 倒數 3、2、1 → 白光閃 → 連拍 4 張（間隔約 1.2 秒）→ 合成直式黑白四格底片條（高對比＋顆粒＋白邊＋日期）→ 可下載 PNG 或重拍。

互動細節：
- 布簾開合用「關簾／開簾」兩層背景淡入切換（約 600ms），兩層構圖一致
- 預覽畫面左右鏡像；拍照時有白色閃光層
- 拍完關閉鏡頭

技術約束：
- getUserMedia 取前鏡頭；說明需要在 localhost 或 HTTPS 開啟
- 權限被拒、沒有鏡頭、或非安全來源時：頁內顯示說明，並提供「上傳四張照片」或「用示範照片」的替代路徑，流程照樣能走完
- 手機：直式版面，按鈕至少 44px，使用 Pointer Events；機身縮放塞進 100dvh
- prefers-reduced-motion：取消閃光與布簾動畫，改成直接切換

不可做：不要做成現代扁平 UI 卡片；不要彩色濾鏡；不要讓成品變成正方形單張。
```

## Claude Design brief 卡
```markdown
# 視覺 brief：{專案名}

- **風格**：復古自拍亭（老式投幣拍貼機，拉開布簾就開拍）
- **情緒關鍵字**：懷舊、期待、俏皮、儀式感
- **配色**：拉絲銀、深酒紅 #7A0F1C、黑白棋盤、招牌暖黃燈光
- **材質**：拉絲金屬、絨布皺褶、底片顆粒、相紙白邊
- **版面**：單屏，機身置中；手機直式，機身縮放，主按鈕在拇指區
- **核心互動**：拉開布簾 → 倒數 → 閃光連拍；成品是黑白四格底片條
- **一句話流程**：進場 → 拉簾 → 倒數 → 閃光連拍四張 → 拿到四格底片
- **不可做**：扁平現代 UI、彩色濾鏡、正方形單張成品
- **要交付的畫面**：關簾首屏、開簾倒數中、閃光瞬間、四格成品、手機首屏
```
